# SkyPoint for Android

The SkyPoint sky on a phone. Hold it up like a window (back camera towards the sky) and it shows what's there: stars, constellations, planets, the Moon in its real phase, Messier objects, and the ISS, Tiangong and Hubble with their tracks.

- **True north out of the box.** Android's rotation vector is referenced to magnetic north; the app adds the local declination (`GeomagneticField`) so azimuths are true. If a phone case or a car pulls the compass, SETUP › Align compass fixes it on any bright object.
- **AR camera view** (SETUP › Camera view), pinch to zoom 12°–110°, tap anything to start Find mode.
- **Tonight**: sunset / dark / sunrise, Moon phase, planets with rise and set, bright stars and deep-sky objects up now, next visible ISS pass.
- **Orbit**: live state and 36 h of passes for each satellite; UPDATE ORBITS pulls fresh TLEs from CelesTrak.
- **GPS**: lock state, sky plot of the satellites the phone hears (coloured by constellation), accuracy, signal, position, or pick a city.
- **Info sheet**: tap the lock card (or any row on Tonight / Orbit) for everything SkyPoint knows about the object: where to look, rise / highest / set, distance and light-time, star colour and temperature from B−V, brightness vs the Sun, Moon phases, satellite speed / period / inclination / next passes, then the Wikipedia summary (fetched on request, cached, shown as plain text) with a Read on Wikipedia button. Offline it says so and offers a Wikipedia search instead.
- **Layers** (button at the top left of the sky, or Settings › Layers): stars, constellations, planets, Sun and Moon, satellites, deep sky, labels, grid. Presets for Default (all objects, no drawings) / Everything / Naked eye / Planets only / Satellites only / Deep sky only / Constellations only; hold a tile to show only that layer. Hidden layers are skipped when the reticle picks a target too.
- **Constellation joints**: every star a figure connects is drawn at its real scale (size from its magnitude, colour from its temperature) with a faint ring, even when it's below the current star limit or the Stars layer is off, and the lines stop just short of each disc.
- **Constellation art** (off by default): 30 of the Stellarium illustrations by Johan Meuris (Free Art License) — both dippers, the 12 zodiac signs, Orion, Cassiopeia, Cygnus, Lyra, Aquila, Pegasus, Andromeda, Perseus, Canis Major, Draco, Hercules, Boötes, Auriga, Cepheus, Centaurus and Crux — drawn over the sky, each pinned by three anchor stars with an affine transform, so a bull sits on Taurus and a hunter on Orion. The constellation you're pointing at lights up; the rest stay faint. Its own layer (on in Everything and Constellations only). Edit `MAIN` in `tools/gen_art.py` to change the set, or pass `all` for all 85.
- **Screen rotation** (Settings › Pointing): Portrait, Auto (follows the phone, respects the system rotation lock) or Landscape. The camera maths remaps the rotation-vector axes for 90 / 180 / 270° so the sky stays put whichever way the phone is held.
- Blips and vibration on lock / find / pass alerts, with a volume slider; night (red) mode.

## Install

Download `SkyPoint_1.0_Beta_1.apk` from the flasher page on the phone, open it, allow "install unknown apps" for the browser, and if Play Protect complains tap **More details › Install anyway**. Allow location (and camera if you want AR).

## How it's built

```
android/
  AndroidManifest.xml          com.skirf.skypoint, minSdk 26, targetSdk 34, portrait
  src/.../MainActivity.java    WebView shell + the window.SkyPointNative bridge
  res/                         icons, theme
  assets/www/                  the app itself
    index.html, style.css, app.js
    lib/catalog.js             stars/figures/DSOs, generated by tools/gen_catalog.py (same data as the watch)
    lib/astronomy.min.js       Astronomy Engine 2.1.19 (MIT)
    lib/satellite.min.js       satellite.js 7.1.0 SGP4 (MIT)
    lib/art.js + art/*.webp    constellation illustrations and their anchor stars (tools/gen_art.py)
    fonts/                     Saira Semi Condensed 400–700 (same family as Wardriver / Open Net), OFL
  dev/stub.js                  fake sensors/GPS for trying the native paths in a desktop browser
  build.sh                     aapt2 -> javac -> dx -> zipalign -> apksigner (no Gradle)
```

The page is served from `https://appassets.androidplatform.net/` by `shouldInterceptRequest`, so it's a secure origin (camera and localStorage work) and nothing touches the network except the TLE download.

Bridge (`window.SkyPointNative`): `orientation()` → `"x,y,z,w,accuracy"` rotation-vector quaternion · `location()` → JSON · `gnss()` → satellites `[az, el, cn0, used, constellation]` · `declination(lat, lon, alt)` · `vibrate(ms)` · `requestLocation()` · `hasCamera()` / `requestCamera()` · `fetchText(urls)` → `SP_onFetch(ok, text)` · `rotation()` / `setRotation(mode)` · `openUrl(url)` (https only, opens the browser) · `version()`. Back button calls `SP_back()`.

Camera maths: device axes in world (E, N, U) come straight from the quaternion; the view looks along −Z (out of the back), screen right is +X, screen up is +Y. Stars are rotated J2000 → horizon once a second with `Rotation_EQJ_HOR`; planets use `Equator` + `Horizon` (with refraction).

## Building

You need a JDK, `aapt2`, `dalvik-exchange` (dx), `zipalign`, `apksigner` (Debian/Ubuntu: `apt install aapt2 dalvik-exchange zipalign apksigner default-jdk`) and an API 34 `android.jar` in `tools/`.

```
cd android
SKYPOINT_KS_PASS=yourpassword ./build.sh
```

**Signing key.** `tools/release.jks` is not in the source. Keep yours private and keep using the same one: Android only installs an update over an app signed with the same key. To make a new one:

```
keytool -genkeypair -keystore tools/release.jks -alias skypoint -keyalg RSA -keysize 3072 -validity 10000
```

Bump `android:versionCode` (and `versionName`) in the manifest for each release.

## Working on the UI in a browser

Serve `assets/www/` with any static server and open e.g.
`index.html?lat=41.88&lon=-87.63&az=150&alt=35&fov=70&nointro&utc=2026-11-12T04:00:00Z`.
Without the native bridge it falls back to drag-to-look and wheel zoom. Other parameters: `page=tonight|orbit|gps|setup`, `find=planet:Jupiter`, `shot` (no toasts).
To exercise the sensor path, copy `dev/stub.js` next to `index.html`, load it before `lib/catalog.js`, and use `saz=` / `salt=` to aim the fake phone.

## Look and feel

The phone UI is styled as a precision instrument: true black, frosted glass panels with hairline dividers, Saira Semi Condensed throughout, the same family as the Wardriver and Open Net apps, one cool accent (`#7de2ee`) that turns ember (`#ffb35c`) when the reticle locks. Pages are centred with a hero at the top (Moon phase, next pass, satellite plot), a stat strip, then grouped lists. City picking and compass alignment open as bottom sheets: tap a row, the ✕, the dim background, swipe the sheet down, or press Back.

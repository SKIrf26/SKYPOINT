# Changelog

All notable changes to this project are listed here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0-beta.1] - 2026-11-11

First public release: **Beta 1**.

### Added
- Watch firmware for the LilyGO T-Watch Ultra (standalone and as a Launcher app) and the Waveshare ESP32-C6-Touch-AMOLED-2.06.
- Sky view with a lock-on reticle, info card, compass tape, altitude ladder, horizon and ground; tap-to-zoom 90° / 60° / 35° / 20°; "See through Earth".
- Catalogue: 1,675 stars (HYG v4.1), 88 constellation figures (Stellarium modern), Sun, Moon with phase, seven planets, 109 Messier objects.
- Satellites: SGP4 tracking of the ISS, Tiangong and Hubble, own pass finder (horizon crossings with bisection, golden-section peak), visibility (sunlit satellite, dark sky), 2-minute pass alerts that start Find mode at rise.
- Tonight, Orbit, GPS (T-Watch) and Setup pages; Find mode with arrow, ticks and buzzes.
- Heading alignment on the Moon, a planet, a bright star or "Face north"; one-step re-align on the locked object.
- T-Watch: GPS time and position (saved to the RTC and flash), GPS page with satellite radar and lock alert, Wi-Fi orbit updates, `/skypoint/wifi.txt` and `/skypoint/tle.txt` on the SD card, Exit to Launcher.
- C6: Wi-Fi sync (NTP time, ip-api.com location, CelesTrak orbits), city picker, QMI8658 + Mahony fusion with gyro-bias learning, BOOT/PWR buttons.
- Sounds (two-voice synth: tap, key, lock, find, align, GPS, alert, boot) with a volume slider; vibration on the T-Watch.
- Big-key Wi-Fi keyboard (after the Wardriver design); night vision; labels Few / Normal / Lots; time zone and US daylight saving.
- SkyPoint for Android 1.0 Beta 1: true-north compass, camera view, pinch zoom, Layers with presets and hold-to-solo, constellation drawings (Johan Meuris, Free Art License), constellation joints drawn to scale, info sheet with Wikipedia summaries, Tonight / Orbit / Location / Settings pages, GPS sky plot, compass alignment, portrait / auto / landscape rotation, Saira Semi Condensed type. Built without Gradle (`android/build.sh`).
- Web installer (`web/`) using ESP Web Tools, with an Android download section.
- User guide (PDF, normal and two booklet versions), generated by `tools/guide/make_guide.py`.
- Logo and app icon in the SKIrF sticker style (`tools/make_logo.py`).

### Fixed (during the private beta)
- T-Watch: black screen from an endless FFat mount when no FFat partition exists (LilyGoLib `initFatfs` disabled).
- T-Watch: reboot loop from the task watchdog; background workers now run at idle priority.
- C6: black screen when built for 16 MB flash; images are built for the board's 4 MB.
- Choppy rendering and slow page switches: SRAM render stripes with DMA, a display list per frame, and Tonight / Orbit computed on a background worker.
- Android: the city picker could re-point its buttons while the Location page refreshed; the info sheet closed straight away after a tap (ghost click).
